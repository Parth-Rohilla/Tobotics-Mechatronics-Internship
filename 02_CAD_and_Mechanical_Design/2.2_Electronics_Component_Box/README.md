# Electronics Component Box

## Overview

An electronics component enclosure designed in Fusion 360 to provide a structured housing for electronic components.

The design includes a hinged lid and internal features for mounting and accommodating components such as an ESP32 and boost module.

## Design

![Electronics Component Box](/Images/CAD/electronic_components_box_CAD.png)

## Features

- Enclosed component housing
- Hinged lid
- Internal mounting/support features
- Space for ESP32 and boost module
- Design consideration for component placement and wiring

## CAD Software

- Autodesk Fusion 360
