# Piston Cup

## Overview

A Piston Cup trophy model designed in Fusion 360 as a CAD and 3D-printing exercise.

The model was developed through two design versions, followed by STL export for 3D printing.

## 3D-Printed

## Development

Two versions of the CAD model were developed:

- **Version 1:** Initial Piston Cup design.
- **Version 2:** Modified and improved version of the design.

The final design was exported as an STL file for 3D printing.

## CAD Software

- Autodesk Fusion 360

## Files

- `piston_cup_v01.f3d` — Initial CAD model
- `piston_cup_v02.f3d` — Updated CAD model
- `piston_cup.stl` — STL file prepared for 3D printing

## Learning Outcomes

- 3D modelling in Fusion 360
- Iterative design development
- Preparing a CAD model for 3D printing
- STL export
- Understanding the transition from CAD model to physical object
