## 03 — Major Project

### Hackable Combination Vault

The Hackable Combination Vault was the major personal project developed during the internship.

The project combines:

- Arduino-based control
- Keypad input
- Display feedback
- LEDs and buzzer
- Servo actuation
- Mechanical CAD
- Front-panel mechanism
- Hinges and door movement
- Locking mechanism studies
- Wokwi simulation

### Project Evolution

The project evolved through several stages:

**Art Thief Vault → Syblin Concept → Mechanical Studies → Hackable Vault**

The initial Art Thief Vault established the basic password-based interaction. The Syblin concept then explored a more mechanically complex interactive design. After evaluating the mechanical complexity and practical limitations, the project was redirected toward the Hackable Vault.

The Hackable Vault retained the core idea of password-driven physical interaction while moving toward a more practical mechanical design.

### Current Status

**In Progress / Prototype**

The project reached a substantially developed design stage during the internship. Electronics, simulation and major mechanical concepts were developed, while complete software and full mechanical integration remained unfinished.
